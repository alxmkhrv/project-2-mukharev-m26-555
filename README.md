
# Примитивная база данных

## Описание проекта

Примитивная база данных — программа, которая реализует консольную систему управления таблицами.

Программа позволяет:
- Создавать таблицы с заданными столбцами и типами данных.
- Просматривать список существующих таблиц.
- Удалять таблицы.
- Сохранять структуру таблиц в JSON-файле.
- Добавлять, просматривать, изменять и удалять записи.
- Сохранять данные каждой таблицы в отдельном JSON-файле.
- Выводить записи в табличном формате с помощью PrettyTable.

Поддерживаемые типы данных: `int`, `str`, `bool`.

Проект разработан на Python 3.12 с использованием пакетного менеджера `uv`.

## Установка и запуск

Для работы с проектом необходимы Python 3.12 и пакетный менеджер `uv`.

### Сборка пакета

В корневой директории проекта выполните:

```bash
uv build
```

После сборки в директории `dist/` появятся файлы `.whl` и `.tar.gz`.

### Установка пакета

Установите собранный пакет командой:

```bash
uv tool install dist/project_2_mukharev_m26_555-0.1.0-py3-none-any.whl
```

Если пакет уже установлен, используйте `--force` для переустановки.

### Запуск базы данных

После установки запустите программу:

```bash
database
```

Для запуска непосредственно из проекта:

```bash
uv run database
```

Альтернативная команда — `uv run project`.


### Команды Makefile

- `make install` — установка зависимостей.
- `make run` — запуск программы.
- `make build` — сборка пакета.
- `make lint` — проверка кода через Ruff.


## Управление таблицами

После запуска программы доступны пять команд:

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец:тип> ...` | Создать таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу |
| `help` | Показать справочную информацию |
| `exit` | Завершить программу |

Поддерживаемые типы данных: `int`, `str`, `bool`.

При создании таблицы автоматически добавляется столбец ID:int. Пользователь не должен указывать его при создании таблицы или добавлении записей.

Метаданные таблиц сохраняются в файле `db_meta.json`.

## CRUD-операции

Программа поддерживает добавление, просмотр, изменение и удаление записей. Данные каждой таблицы сохраняются в отдельном JSON-файле в директории `data/`.

| Команда | Описание |
|---|---|
| `insert into <таблица> values (<значения>)` | Добавить запись |
| `select from <таблица>` | Показать все записи |
| `select from <таблица> where <условие>` | Найти записи по условию |
| `update <таблица> set <условие> where <условие>` | Изменить записи |
| `delete from <таблица> where <условие>` | Удалить записи |
| `info <таблица>` | Информация о таблице |

При добавлении записи необходимо указать значения всех пользовательских столбцов. ID генерируется автоматически. Строковые значения указываются в кавычках.

Результаты запросов `select` отображаются с помощью PrettyTable.

## Декораторы и кэширование

Для повышения надёжности и удобства работы с базой данных реализованы следующие декораторы:

- `handle_db_errors` — обрабатывает ошибки `KeyError`, `ValueError` и `FileNotFoundError`, выводя понятные сообщения.
- `confirm_action` — запрашивает подтверждение перед удалением таблиц и записей.
- `log_time` — измеряет время выполнения операций `insert` и `select` с помощью `time.monotonic()`.

### Подтверждение удаления

Перед выполнением команд `drop_table` и `delete` программа запрашивает подтверждение:

```text
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:
```

- `y` — выполнить удаление.
- Любой другой ответ — отменить операцию.

При удалении таблицы удаляются её метаданные и JSON-файл с данными.

### Кэширование запросов SELECT

Для кэширования реализовано замыкание `create_cacher()`.

При повторном выполнении одинакового запроса `SELECT` результат берётся из кэша без повторного чтения файла.

После успешного изменения данных через `INSERT`, `UPDATE`, `DELETE`, а также создания или удаления таблиц кэш сбрасывается. Это предотвращает использование устаревших результатов.
